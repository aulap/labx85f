Kenali ScriptBlocker

ScriptBlocker dirancang untuk membantu melindungi Windows dari serangan malware yang memanfaatkan skrip dan utilitas bawaan sistem. Dengan membatasi eksekusi PowerShell, Windows Script Host, dan LOLBin tertentu, ScriptBlocker membantu mengurangi risiko serangan fileless malware serta penyalahgunaan perintah oleh penyerang.

Cocok untuk

  • Mengurangi risiko serangan malware yang memanfaatkan PowerShell, CMD, dan Windows Script Host.
  • Membatasi penyalahgunaan LOLBin yang sering digunakan dalam serangan fileless malware.
  • Memperkuat keamanan Windows dengan membatasi eksekusi skrip dan perintah yang tidak diperlukan.

Tampilan ScriptBlocker v3

Fitur Utama

Tiga kontrol utama untuk membatasi eksekusi skrip dan utilitas Windows.

FEATURE 01

Script Host Controls

Membatasi penggunaan WScript, CScript, MSHTA, dan host skrip lain yang dapat menjalankan kode.

FEATURE 02

PowerShell & Shell Policies

Mengatur pembatasan PowerShell, CMD, dan penerjemah perintah tertentu untuk mengurangi eksekusi yang tidak diperlukan.

FEATURE 03

LOLBin Restrictions

Membatasi utilitas bawaan Windows seperti regsvr32, certutil, dan bitsadmin yang dapat disalahgunakan untuk menjalankan perintah atau memproses file.

Cara Memulai

  1. Jalankan ScriptBlocker dan berikan izin administrator jika diminta.
  2. Pilih script host, shell, atau LOLBin yang ingin dibatasi.
  3. Klik Apply Changes untuk menerapkan pengaturan.
  4. Periksa kembali aplikasi dan fitur Windows yang biasa digunakan.

Pertanyaan Umum

Apakah ScriptBlocker merupakan antivirus?

Bukan. ScriptBlocker membatasi eksekusi program skrip dan utilitas Windows tertentu. Perlindungan antivirus tetap diperlukan.

Apakah semua LOLBin harus diblokir?

Tidak. Sejumlah utilitas Windows juga dipakai oleh sistem dan aplikasi yang sah. Pilih pembatasan sesuai kebutuhan.

Apakah pembatasan dapat memengaruhi aplikasi lain?

Ya. Aplikasi yang membutuhkan PowerShell, CMD, atau utilitas terkait mungkin tidak berjalan normal jika dibatasi.
